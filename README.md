# multi-camera-fpga-vision-system
This project implements a real-time multi-camera vision system on FPGA, designed to process and synchronize multiple video streams using a hardware pipeline architecture.

The system simulates multiple camera inputs and applies image processing operations such as filtering and edge detection, while maintaining strict timing constraints through synchronization signals (VSYNC, HSYNC, PCLK).

This project focuses on high-performance parallel processing, real-time constraints, and hardware design for computer vision applications.
